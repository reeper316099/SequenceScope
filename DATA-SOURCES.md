# DATA-SOURCES.md

Every bundled sequence set was downloaded from its real source by accession with `tools/fetch_examples.py` (nothing was typed or recalled from memory), checksummed, and described in a `metadata.json` next to the FASTA. This file is generated by `tools/gen_data_sources.py` from those files.

The app itself makes **no network requests**; the downloads happen only when a developer runs the script.

## Substitution matrices

BLOSUM45, BLOSUM62 and BLOSUM80 come from the NCBI BLAST matrices directory (https://ftp.ncbi.nlm.nih.gov/blast/matrices/; file header: “Matrix made by matblas from blosum62.iij”), downloaded 2026-11-08 into `data/matrices/`; `src/bio/matrices.data.ts` is generated from them by `tools/gen-matrices.mjs` (never typed by hand).

| File | SHA-256 |
|---|---|
| BLOSUM45 | `19a077d5060a94a6212ad609df303a240463873a69694e9f576c5762fbffdb09` |
| BLOSUM62 | `85510d3846ee6d5f4778e425cf8daf6e0dbb889b306f2d13434e1254780efb40` |
| BLOSUM80 | `2e597176b8092808ba199cfc9d80dc8d657b5a3e5015dfb81d557285819ce187` |

- **Independent check:** the three files are byte-identical to the copies bundled with Biopython 1.86, and BLOSUM62 is cell-for-cell identical to an EMBOSS copy (576 cells); all are symmetric. This is a consistency check, not a truly independent derivation: all copies descend from the same NCBI/matblas files. The original Henikoff files (blocks.fhcrc.org) were not reachable.
- **Citation:** Henikoff S, Henikoff JG (1992). Amino acid substitution matrices from protein blocks. Proc Natl Acad Sci USA 89(22):10915-10919. doi:10.1073/pnas.89.22.10915 (verified against Crossref).
- **License status: NOT formally confirmed.** The files carry no license text. They are small numeric tables distributed publicly by NCBI inside its BLAST software and bundled by Biopython and EMBOSS. I could not find an explicit redistribution grant; if you need certainty (for example before wider distribution), ask NCBI or generate the numbers from the published paper. This is not legal advice.

## Other bundled or derived material

- **Worked examples** (`tests/fixtures/worked-examples/`): short facts from Rosalind (problems GLOB and GAFF, rosalind.info) and Wikipedia (Needleman–Wunsch, Smith–Waterman, UPGMA and Neighbor joining articles; text is CC BY-SA), used only as test data with the source URL and access date (2026-11-08) recorded next to each. Not shipped in the installers.
- **Reference fixtures** (`tests/fixtures/reference/`): outputs of Biopython 1.86 and SciPy 1.11.1 on random cases generated by `tools/`; they record versions, parameters and seeds. Not shipped in the installers.
- **MAFFT 7.526** (BSD-3-Clause) was used once to make the two `aligned.fasta` files; it is not part of the app.
- **Libraries bundled into the app** (all permissive): Tauri and its dialog, opener and clipboard plugins (MIT or Apache-2.0), the Rust crates they and the core depend on (`Cargo.lock` lists every one with its exact version), zod (MIT), Chart.js (MIT). The app uses the operating system's web view, which is not bundled. The development-only test bridge (`tiny_http`, MIT or Apache-2.0) is not part of the app.
